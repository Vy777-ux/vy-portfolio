Publicar o site

Envie a página atual, textos, projetos, imagens, vídeos, cores e animações para seu repositório do GitHub Pages.

A senha é enviada somente ao servidor HTTPS de publicação e nunca fica salva.

Salvar uma cópia local

Salve as alterações neste navegador. Quem visitar o site verá apenas o portfólio, sem as ferramentas de edição.

É necessário configurar uma vez: publique o Cloudflare Worker incluído, defina o token do GitHub e uma senha longa como segredos do servidor e configure o repositório Pages. Consulte PUBLISHING.md.
